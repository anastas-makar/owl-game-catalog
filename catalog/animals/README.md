# Животные

Животное — действующее лицо игрового мира.

Животное живёт в доме или замке, может готовить, участвовать в экспедициях и занимать должности мэра города и правителя страны.

Животные никогда не выдаются через мешочек, лавку или `lootBundle`.

Если в городе есть свободный дом или замок, в игре начинают появляться животные, которые ищут дом.

Игрок может решить, заселить животное в свободный дом или замок либо прогнать его.

При заселении игрок даёт животному имя.

Общие правила работы с каталогом находятся в [`catalog/README.md`](../README.md).

## Пример

```json
{
  "templateId": "lonely-dog",
  "initialDisplayName": "Одинокий пёс",
  "kind": "Пёс",
  "sourceImageUrl": "https://example.org/lonely-dog.png"
}
```

В опубликованном каталоге вместо `sourceImageUrl` используется `imageKey`. Подробнее см. общие правила работы с изображениями в [`catalog/README.md`](../README.md).

## `templateId`

`templateId` — стабильный идентификатор шаблона животного.

Например:

```json
{
  "templateId": "lonely-dog"
}
```

`templateId` должен быть уникален среди животных и не должен изменяться после публикации шаблона.

## Вид животного (`kind`)

`kind` — вид животного, который используется при отображении животного в игре.

Например:

```json
{
  "kind": "Пёс"
}
```

Другими значениями могут быть, например:

```text
Кот
Сова
Свинья
```

## Начальное имя (`initialDisplayName`)

`initialDisplayName` — название животного до того, как игрок поселил его и дал ему собственное имя.

Например:

```text
Одинокий пёс
Грустный кот
Потерянная сова
```

В сообщении о животном, которое ищет дом, может использоваться `initialDisplayName`:

> Одинокий пёс ищет дом.

После заселения используется имя, которое дал игрок.

Например, если игрок дал псу имя Барбос и поселил его в доме, в описании дома может выводиться:

> Здесь живёт пёс Барбос.

Таким образом, `initialDisplayName` относится к шаблону животного, а имя Барбос — к конкретному животному игрока.

## Изображение

Шаблон животного содержит изображение:

```json
{
  "sourceImageUrl": "https://example.org/lonely-dog.png"
}
```

В опубликованном каталоге используется:

```json
{
  "imageKey": "animals/lonely-dog.webp"
}
```

Изображение относится к шаблону животного и не меняется, когда игрок даёт животному собственное имя.

## Проверка

Перед pull request проверьте:

* `templateId` уникален среди животных;
* `initialDisplayName` не пуст;
* `kind` не пуст;
* `initialDisplayName` подходит для сообщения о животном, которое ищет дом;
* изображение передано через `sourceImageUrl` или `imageKey`, а не добавлено бинарным файлом в репозиторий.
