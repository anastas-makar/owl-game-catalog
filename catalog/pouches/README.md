# Мешочки

Каждый JSON-файл описывает один декоративный шаблон мешочка. Мешочки используются только как изображения в анимации выбора награды.

Шаблон мешочка не является объектом игрового мира. Так как все мешочки участвуют в анимации на одном экране, слишком большое количество мешочков не нужно. Пока не планируется увеличивать количество мешочков.

## Формат

```json
{
  "templateId": "pouch1",
  "imageKey": "pouches/pouch1.png",
  "tags": [
  "default"
  ]
}
```

Имя файла должно совпадать с `templateId`: шаблон `pouch1` хранится в `pouch1.json`.

`imageKey` — ключ объекта в S3 без начального `/`. Для стандартного набора используются ключи `pouches/pouch1.png` … `pouches/pouch32.png`.

## Теги

Поле `tags` обязательно, должно быть непустым и не должно содержать пустых или повторяющихся значений.

Текущий обычный набор имеет тег:

```text
default
```

В дальнейшем отдельные оформления могут использовать, например, `new_year`, `halloween` или `spring`. В игре будет показан набор с определённым тегом; по умолчанию используется `default`.

## Проверка

Сейчас не планируется увеличивать количество мешочков, чтобы не перегружать анимацию.

Перед pull request проверьте:

* `templateId` уникален среди мешочков;
* имя JSON-файла совпадает с `templateId`;
* изображение задано через `imageKey` или допустимый для рабочей ветки `sourceImageUrl`;
* `imageKey` не начинается с `/`;
* присутствует хотя бы один непустой тег;
* один и тот же тег не повторяется внутри шаблона.
