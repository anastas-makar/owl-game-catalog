# Карты

Каждый файл описывает один шаблон карты и её слоты.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Главное о слотах

Слот — не самостоятельный шаблон. Он описывает стабильное место внутри конкретной карты, поэтому использует `slotId`, а не `templateId`.

Полная идентичность слота задаётся парой:

```text
map templateId + slotId
```

Одинаковый `slotId` допустим в разных картах, но не должен повторяться в одном массиве слотов одной карты.

## Каркас карты

```json
{
  "templateId": "swamp-map",
  "name": "Болотная карта",
  "sourceImageUrl": "https://example.org/swamp-map.png",
  "completionMedalTemplateId": "swamp-liberator",
  "locationSlots": [],
  "enemySlots": []
}
```

Дополните каркас обязательными полями текущего `CatalogMapImport`.

## Слоты локаций

Пример фиксированной локации:

```json
{
  "slotId": "north-grotto",
  "mode": "FIXED",
  "x": 0.2,
  "y": 0.35,
  "fixedLocationTemplateId": "old-grotto"
}
```

Если `mode` равен `FIXED`, `fixedLocationTemplateId` должен ссылаться на существующую локацию.

Для других режимов используйте только поля, предусмотренные текущим `CatalogLocationSlot`.

## Слоты врагов

```json
{
  "slotId": "north-gate",
  "x": 0.25,
  "y": 0.4,
  "allowedTypes": [
    "UNDEAD"
  ],
  "requiredTags": [
    "swamp"
  ]
}
```

`allowedTypes` должен содержать значения enum `EnemyType`. `requiredTags` должны совпадать с техническими тегами врагов.

## Координаты

`x` и `y` должны использовать ту же систему координат, что существующие карты. Перед добавлением слота сравните значения с текущими файлами и клиентским отображением.

## Медаль за завершение

```json
{
  "completionMedalTemplateId": "swamp-liberator"
}
```

Ссылка должна вести на существующую медаль из [`../medals/`](../medals/).

## Изменение слота

Если координаты или ограничения изменились, но `slotId` сохранился, это редактирование существующего слота. Если старый `slotId` исчез и появился новый, это удаление и добавление.

## Проверка

- `slotId` непустые и уникальны в пределах соответствующего массива;
- фиксированные локации существуют;
- медаль существует;
- enum типов врагов существует;
- теги согласованы с врагами;
- координаты находятся в допустимом диапазоне текущей модели.
