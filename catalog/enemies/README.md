# Враги

Каждый файл описывает один корневой шаблон врага.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Как начать

Набор характеристик врага зависит от текущего `CatalogEnemyImport`. Скопируйте существующего врага, максимально близкого по механике, и измените его поля.

Не добавляйте характеристики «на будущее», которых нет в import DTO.

## Базовый каркас

```json
{
  "templateId": "swamp-ghoul",
  "name": "Болотный упырь",
  "sourceImageUrl": "https://example.org/swamp-ghoul.png"
}
```

Дополните каркас обязательными полями текущей модели.

## Типы и теги

Карты могут ограничивать врагов через `allowedTypes` и `requiredTags` в `enemySlots`.

Поэтому:

- тип врага должен соответствовать enum `EnemyType`;
- технические теги должны быть стабильными;
- теги пишутся латинскими строчными буквами;
- новый тег добавляется только при наличии понятного игрового применения.

Пример используйте только при наличии этих полей в DTO:

```json
{
  "templateId": "swamp-ghoul",
  "type": "UNDEAD",
  "tags": [
    "swamp",
    "weak"
  ]
}
```

## Изображение

В pull request допускается `sourceImageUrl`; в релизе он будет заменён на `imageKey`.

## Проверка

- `templateId` уникален среди врагов;
- тип существует в `EnemyType`;
- теги согласованы со слотами карт;
- не добавлены неизвестные DTO поля;
- временная ссылка открывается без авторизации.
