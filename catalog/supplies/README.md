# Припасы

Припас — корневая сущность каталога. 

Припасы нельзя получить напрямую из мешочка, лавки, после завершения экспедиции или квеста. 

Припасы можно получить после сбора урожая в саду или огороде. Также припасы можно приготовить по рецептам из других припасов.

Таким образом, на припасы могут ссылаться растения, предметы сада и рецепты.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Каркас

```json
{
  "templateId": "pumpkin",
  "name": "Тыква",
  "description": "Можно есть и сырой, но лучше её приготовить.",
  "sourceImageUrl": "https://example.org/pumpkin.png",
  "effectType": "HEAL",
  "effectAmount": 50
}
```

### Какие бывают типы эффекта (`effectType`)

Припасы можно брать с собой в экспедицию. Во время экспедиции они могут восстановить здоровье животного или нанести урон врагу. От этого напрямую зависит исход экспедиции.

Типы эффекта:

- `HEAL` — восстанавливает здоровье животного;
- `DAMAGE` — наносит урон врагу;
- `NO_EFFECT` — не оказывает эффекта.

### Сила эффекта (`effectAmount`)

`effectAmount` определяет силу эффекта:

- для `HEAL` — количество восстанавливаемых очков здоровья;
- для `DAMAGE` — количество урона, наносимого врагу;
- для `NO_EFFECT` — `0`.

## Ссылки

На припасы могут ссылаться:

- растения через `supplyTemplateId`;
- предметы сада через `supplyTemplateId`;
- рецепты через `resultSupplyTemplateId`;
- ингредиенты рецептов через `supplyTemplateId`.

Поэтому опубликованный `templateId` припаса нельзя менять без исправления всех ссылок.

## Проверка

- `templateId` уникален среди припасов;
- название понятно игроку;
- поля соответствуют import DTO;
- опубликованный `templateId` не изменён;
- изображение передано ссылкой или ключом.
