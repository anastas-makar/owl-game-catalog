# Мебель

Каждый JSON-файл описывает один шаблон предмета мебели.

Мебель можно размещать в комнатах домов и замков.

Предмет мебели сначала должен быть получен игроком одним из доступных способов, а затем размещён в комнате. При размещении игрок платит количество бриллиантов, указанное в поле `price`.

Таким образом, `allowedAcquisitionSources` определяет способы получения мебели, а `price` — стоимость её размещения. Это разные механики.

Особый тип мебели — холодильник. Если в комнате есть холодильник, а в доме или замке живёт животное, в этой комнате можно готовить.

Подробнее о готовке по рецептам см. в [`../recipes/README.md`](../recipes/README.md).

## Размеры мебели

Размеры мебели задаются относительно ширины идеальной квадратной комнаты.

Ширина такой комнаты принимается за `1`.

Например:

```json
{
  "width": 0.42,
  "height": 0.28
}
```

означает, что предмет занимает по ширине около 42% ширины комнаты, а по высоте — около 28%.

Размеры мебели в игре намеренно уменьшены относительно реалистичных пропорций. Это связано как с размером игровых персонажей-животных, так и с необходимостью удобно размещать несколько предметов в двухмерной комнате.

При добавлении нового предмета следует сравнивать его размеры с похожей мебелью, уже существующей в каталоге.

Общие правила работы с каталогом находятся в [`catalog/README.md`](../README.md).

## Полный пример

```json
{
  "templateId": "red-sofa",
  "name": "Красный диван",
  "sourceImageUrl": "https://example.org/red-sofa.png",
  "price": 350,
  "height": 0.28,
  "width": 0.42,
  "type": "OTHER",
  "allowedAcquisitionSources": [
    "POUCH",
    "SHOP"
  ]
}
```

В рабочей ветке вместо `imageKey` можно использовать временный публичный `sourceImageUrl`.

Перед публикацией каталога временные ссылки заменяются на `imageKey`.

## Поля мебели

### `templateId`

Обязательный стабильный идентификатор шаблона мебели.

```json
{
  "templateId": "red-sofa"
}
```

`templateId`:

* должен быть непустой строкой;
* должен быть уникален среди всех шаблонов мебели;
* сохраняется при редактировании существующего предмета.

Изменение `templateId` означает удаление старого шаблона и добавление нового.

### `name`

Обязательное название предмета, отображаемое игроку.

```json
{
  "name": "Красный диван"
}
```

### Изображение

Каждый предмет мебели должен иметь изображение.

В рабочей ветке допускается:

```json
{
  "sourceImageUrl": "https://example.org/red-sofa.png"
}
```

В опубликованном каталоге используется:

```json
{
  "imageKey": "furniture/red-sofa.webp"
}
```

Не следует одновременно указывать `imageKey` и `sourceImageUrl`.

## Цена

Поле `price` задаёт стоимость размещения мебели в комнате в бриллиантах.

```json
{
  "price": 350
}
```

`price` должен быть неотрицательным целым числом.

Значение `0` означает, что предмет можно разместить бесплатно.

Цена размещения не определяет способ получения мебели. Способы получения задаются отдельно через `allowedAcquisitionSources`.

## Размер

Поля `width` и `height` задают размер предмета в комнате:

```json
{
  "width": 0.42,
  "height": 0.28
}
```

`width` и `height` должны быть числами больше 0 и не больше 1.

За единицу принимается ширина идеальной квадратной комнаты.

Размеры следует подбирать относительно уже существующей мебели. Не следует пытаться воспроизводить реальные пропорции предметов буквально: игровые размеры специально адаптированы для интерфейса и размещения мебели в комнате.

## Тип мебели

Поле `type` определяет технический тип предмета.

Допустимые значения:

* `REFRIGERATOR` — холодильник;
* `OTHER` — любая другая мебель.

Например:

```json
{
  "type": "REFRIGERATOR"
}
```

`REFRIGERATOR` имеет специальное игровое значение: наличие холодильника позволяет использовать комнату для приготовления еды, если в доме или замке живёт животное.

Для всей мебели, которая не является холодильником, следует использовать:

```json
{
  "type": "OTHER"
}
```

Типы вроде `SOFA`, `TABLE`, `BED` или `CHAIR` в каталоге не используются.

## Источники получения

Способы получения мебели можно ограничить через `allowedAcquisitionSources`.

Например, мебель, которую можно получить только как награду за квест:

```json
{
  "allowedAcquisitionSources": [
    "QUEST_REWARD"
  ]
}
```

Отсутствие `allowedAcquisitionSources` или значение `null` означает отсутствие ограничений по стандартным источникам получения.

Пустой массив:

```json
{
  "allowedAcquisitionSources": []
}
```

означает, что предмет нельзя получить ни одним из стандартных способов.

Общие правила и полный список источников описаны в [разделе «Источники получения»](../README.md#acquisition-sources).

## Проверка

Перед pull request проверьте:

* `templateId` указан и уникален среди мебели;
* `name` указан;
* изображение передано через `sourceImageUrl` или `imageKey`;
* `price` является неотрицательным целым числом;
* `width` и `height` являются числами больше `0` и не больше `1`;
* `type` равен `REFRIGERATOR` или `OTHER`;
* вся обычная мебель использует тип `OTHER`;
* значения `allowedAcquisitionSources`, если они указаны, являются допустимыми источниками получения;
* перед публикацией временные `sourceImageUrl` заменены на `imageKey`.
