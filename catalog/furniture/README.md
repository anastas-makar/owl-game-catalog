# Мебель

Каждый файл описывает один шаблон предмета мебели.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Пример

```json
{
  "templateId": "red-sofa",
  "name": "Красный диван",
  "type": "SOFA",
  "price": 350,
  "height": 0.28,
  "width": 0.42,
  "sourceImageUrl": "https://example.org/red-sofa.png"
}
```

Используйте только enum и поля, которые существуют в текущем `CatalogFurnitureImport`.

## Размеры

`height` и `width` должны использовать ту же систему координат и единицы, что существующая мебель. Перед добавлением нового предмета сравните его с похожими предметами.

## Цена и тип

- `type` должен существовать в enum backend;
- `price` должен соответствовать текущей экономике игры;
- изменение типа существующего предмета может повлиять на фильтры и интерфейс.

## Ограничение получения

Обычная мебель не требует белого списка. Только квестовая мебель:

```json
{
  "allowedAcquisitionSources": [
    "QUEST_REWARD"
  ]
}
```

Временно недоступная мебель:

```json
{
  "allowedAcquisitionSources": []
}
```

## Проверка

- имя файла совпадает с `templateId`;
- размеры согласованы с текущей системой размещения;
- enum `type` существует;
- картинка не добавлена в Git;
- временная ссылка публично доступна.
