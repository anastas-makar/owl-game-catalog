# Растения

Каждый файл описывает один шаблон растения.

Растения можно сажать в огороде перед домом или замком.

Когда растение выросло, игрок выбирает, что собрать:

* припасы;
* семена, которые можно снова посадить в огороде.

Поэтому для каждого растения указываются:

* `supplyTemplateId` — какой припас даёт растение;
* `supplyAmount` — сколько единиц припаса можно собрать;
* `seedAmount` — сколько семян можно собрать.

Растения также могут быть получены как лут. Общие правила выбора наград описаны в [документации лута](../LOOT.md).

Общие правила работы с каталогом находятся в [`catalog/README.md`](../README.md).

## Пример

```json
{
  "templateId": "pumpkin-plant",
  "name": "Тыква",
  "description": "Большая оранжевая тыква.",
  "sourceImageUrl": "https://example.org/pumpkin-plant.png",
  "supplyTemplateId": "pumpkin",
  "supplyAmount": 2,
  "seedAmount": 3
}
```

В опубликованном каталоге вместо `sourceImageUrl` используется `imageKey`. Подробнее см. общие правила работы с изображениями в [`catalog/README.md`](../README.md).

## Припас

`supplyTemplateId` должен ссылаться на существующий припас из [`../supplies/`](../supplies/).

Например:

```json
{
  "supplyTemplateId": "pumpkin"
}
```

означает, что при выборе сбора припасов растение даёт припас с `templateId`:

```text
pumpkin
```

## Количество припасов

`supplyAmount` определяет количество единиц припаса, которое игрок получает при сборе урожая.

```json
{
  "supplyAmount": 2
}
```

означает, что растение даёт две единицы припаса.

`supplyAmount` должен быть положительным целым числом.

## Количество семян

`seedAmount` определяет количество семян, которое игрок получает, если вместо припасов выбирает сбор семян.

```json
{
  "seedAmount": 3
}
```

означает получение трёх семян.

`seedAmount` должен быть положительным целым числом.

## Источники получения

Растение может быть получено различными стандартными способами, в том числе как лут.

Если ограничений нет, поле `allowedAcquisitionSources` указывать не нужно.

Если способы получения требуется ограничить, используется белый список `allowedAcquisitionSources`.

Подробнее см. раздел [«Источники получения»](../README.md#acquisition-sources).

Правила использования растений в наградах описаны в [документации лута](../LOOT.md).

## Проверка

Перед pull request проверьте:

* `templateId` растения уникален среди растений;
* `supplyTemplateId` ссылается на существующий припас;
* `supplyAmount` является положительным целым числом;
* `seedAmount` является положительным целым числом;
* значения `allowedAcquisitionSources`, если они указаны, являются допустимыми источниками получения;
* изображение передано через `sourceImageUrl` или `imageKey`, а не добавлено бинарным файлом в репозиторий.
