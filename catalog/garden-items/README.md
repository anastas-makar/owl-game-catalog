# Предметы для сада и пруда

Каждый JSON-файл описывает один шаблон предмета, используемого в садовой механике. В игре такие предметы также называются «находками для сада».

В эту категорию входят разные сущности, которые игрок может размещать в саду или пруду: деревья, водные растения, рыбы, птичьи гнёзда, ульи, домики животных, грибы и другие подобные объекты.

Предметы для сада и пруда используются для получения припасов, как и растения, но работают немного иначе.

Растения выращиваются в огороде. Огород есть возле любого дома и любого замка.

Предметы из `garden-items` размещаются только в саду или пруду. Сад и пруд есть возле замка, но отсутствуют возле обычного дома.

Подробнее о домах, замках, садах и огородах см. в [`../buildings/README.md`](../buildings/README.md).

После размещения предмет периодически даёт определённый припас. Например, яблоня может давать яблоки, улей — мёд, а рыба — охлаждённую рыбу.

В отличие от растений, предметы для сада и пруда не исчезают после сбора припасов и не дают семян. Поэтому размножать их через выращивание нельзя.

Игрок самостоятельно выбирает место для каждого предмета в соответствующем саду или пруду. Слотов, аналогичных `locationSlots` карт, для этой механики нет.

Размещение предметов для сада и пруда бесплатно. Цена в шаблоне не указывается.

Общие правила работы с каталогом находятся в [`catalog/README.md`](../README.md).

## Полный пример

```json
{
  "templateId": "apple-tree",
  "name": "Яблоня",
  "description": "Яблоня, которая регулярно приносит урожай.",
  "sourceImageUrl": "https://example.org/apple-tree.png",
  "supplyTemplateId": "apple",
  "supplyAmount": 3,
  "itemType": "TREE",
  "gardenType": "GARDEN",
  "allowedAcquisitionSources": [
    "POUCH",
    "SHOP"
  ]
}
```

В рабочей ветке вместо `imageKey` можно использовать временный публичный `sourceImageUrl` согласно общим правилам работы с изображениями.

Перед публикацией каталога временные ссылки заменяются на `imageKey`.

## Поля шаблона предмета для сада или пруда

### `templateId`

Обязательный стабильный идентификатор шаблона предмета.

```json
{
  "templateId": "apple-tree"
}
```

`templateId`:

* должен быть непустой строкой;
* должен быть уникален среди всех предметов для сада и пруда;
* сохраняется при редактировании существующего предмета.

Изменение `templateId` означает удаление старого шаблона и добавление нового.

### `name`

Обязательное название предмета, отображаемое игроку.

```json
{
  "name": "Яблоня"
}
```

### `description`

Обязательное описание предмета.

```json
{
  "description": "Яблоня, которая регулярно приносит урожай."
}
```

### Изображение

Предмет должен иметь изображение.

В рабочей ветке допускается:

```json
{
  "sourceImageUrl": "https://example.org/apple-tree.png"
}
```

В опубликованном каталоге используется:

```json
{
  "imageKey": "garden-items/apple-tree.webp"
}
```

Не следует одновременно указывать `imageKey` и `sourceImageUrl`.

## Получаемый припас

Каждый предмет для сада или пруда производит один вид припаса.

Поле `supplyTemplateId` указывает, какой именно припас получается при сборе:

```json
{
  "supplyTemplateId": "apple"
}
```

Значение должно совпадать с `templateId` существующего припаса из [`../supplies/`](../supplies/).

Поле `supplyAmount` задаёт количество единиц припаса, получаемых за один сбор:

```json
{
  "supplyAmount": 3
}
```

`supplyAmount` должен быть положительным целым числом.

После сбора предмет не исчезает и впоследствии снова может дать тот же припас.

В отличие от растений, предметы для сада и пруда не дают семян.

## Место размещения

Поле `gardenType` определяет, где игрок может разместить предмет.

```json
{
  "gardenType": "GARDEN"
}
```

Для предметов из `garden-items` допустимы два значения:

* `GARDEN` — сад;
* `POOL` — пруд.

В общем `GardenType` также существует значение `KITCHEN_GARDEN`. Оно обозначает огород и используется для растений. Для предметов из `garden-items` значение `KITCHEN_GARDEN` недопустимо.

Предметы размещает сам игрок. Заранее заданных слотов в саду и пруду нет.

## Тип предмета

Поле `itemType` задаёт технический тип предмета.

```json
{
  "itemType": "TREE"
}
```

Допустимые значения:

* `TREE` — дерево;
* `FISH` — рыба;
* `WATER_PLANT` — водное растение;
* `HIVE` — улей;
* `ANIMAL_HOUSE` — домик животного;
* `NEST` — гнездо;
* `MUSHROOM` — гриб.

Это не строгая смысловая классификация. Значение `itemType` должно быть одним из перечисленных выше, но используется прежде всего мобильным приложением для технических нужд, в частности для выбора иконки предмета.

Поэтому тип не обязательно должен буквально и исчерпывающе описывать предмет. Следует выбирать наиболее подходящий вариант исходя из того, какая иконка должна использоваться в интерфейсе.

`itemType` и `gardenType` имеют разный смысл:

* `itemType` определяет тип предмета и его отображение;
* `gardenType` определяет место, где предмет можно разместить.

Например:

```json
{
  "itemType": "FISH",
  "gardenType": "POOL"
}
```

или:

```json
{
  "itemType": "TREE",
  "gardenType": "GARDEN"
}
```

## Источники получения

Стандартные способы получения предмета можно ограничить через `allowedAcquisitionSources`.

Например, если предмет можно получить только как награду за квест:

```json
{
  "allowedAcquisitionSources": [
    "QUEST_REWARD"
  ]
}
```

Отсутствие `allowedAcquisitionSources` или значение `null` означает отсутствие ограничений по стандартным источникам получения.

Пустой массив:

```json
{
  "allowedAcquisitionSources": []
}
```

означает, что предмет нельзя получить ни одним из стандартных способов.

Общие правила и полный список источников описаны в [разделе «Источники получения»](../README.md#acquisition-sources).

## Проверка

Перед pull request проверьте:

* `templateId` указан и уникален среди предметов для сада и пруда;
* `name` и `description` указаны;
* изображение передано через `sourceImageUrl` или `imageKey`;
* `supplyTemplateId` указан и ссылается на существующий припас;
* `supplyAmount` является положительным целым числом;
* `itemType` соответствует одному из допустимых типов предметов;
* `gardenType` равен `GARDEN` или `POOL`;
* `KITCHEN_GARDEN` не используется для предметов из `garden-items`;
* значения `allowedAcquisitionSources`, если они указаны, являются допустимыми источниками получения;
* перед публикацией временные `sourceImageUrl` заменены на `imageKey`.
