# Медали

Каждый файл описывает один шаблон медали.

После успешного завершения экспедиции и освобождения карты животное, которое участвовало в экспедиции, получает связанную с этой картой медаль.

Одну карту можно освободить только один раз. В текущей модели с каждой картой может быть связана одна медаль за её освобождение.

Медаль не является обычным лутом: она не указывается в `lootBundle` и для неё не используется `allowedAcquisitionSources`. Медаль за освобождение задаётся непосредственно в описании карты.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Пример

```json
{
  "templateId": "swamp-liberator",
  "title": "Медаль за освобождение болота",
  "description": "Выдана за освобождение болота от монстров.",
  "sourceImageUrl": "https://example.org/swamp-liberator.png"
}
```

В опубликованном каталоге вместо `sourceImageUrl` используется `imageKey`. Подробнее см. общие правила работы с изображениями в [`catalog/README.md`](../README.md).

## Связь с картой

Карта указывает медаль, которая выдаётся после её освобождения, через `completionMedalTemplateId`:

```json
{
  "completionMedalTemplateId": "swamp-liberator"
}
```

Значение `completionMedalTemplateId` должно совпадать с `templateId` существующей медали.

Например, карта:

```json
{
  "templateId": "swamp-map",
  "completionMedalTemplateId": "swamp-liberator"
}
```

выдаёт после освобождения медаль:

```text
swamp-liberator
```

Подробнее об освобождении карт и наградах за экспедицию см. в [документации карт](../maps/README.md).

## `templateId`

`templateId` медали должен быть уникален среди медалей.

После публикации `templateId` считается стабильным. Его изменение потребует исправить все карты, которые ссылаются на эту медаль, а после появления пользовательских данных может также потребовать учёта уже выданных медалей.

## Проверка

Перед pull request проверьте:

* `templateId` медали уникален среди медалей;
* `title` понятно описывает медаль;
* `description` соответствует условию её получения;
* карта, для которой предназначена медаль, ссылается на правильный `templateId`;
* изображение передано через `sourceImageUrl` или `imageKey`, а не добавлено бинарным файлом в репозиторий.
