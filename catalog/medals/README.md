# Медали

Каждый файл описывает один шаблон медали.

Общие правила находятся в [`catalog/README.md`](../README.md).

## Каркас

```json
{
  "templateId": "swamp-liberator",
  "name": "Освободитель болота",
  "description": "Награда за завершение болотной карты.",
  "sourceImageUrl": "https://example.org/swamp-liberator.png"
}
```

Добавьте остальные обязательные поля текущего `CatalogMedalImport`.

## Ссылки с карт

Карта может ссылаться на медаль:

```json
{
  "completionMedalTemplateId": "swamp-liberator"
}
```

Поэтому опубликованный `templateId` медали нельзя менять без одновременного исправления всех карт и учёта пользовательского состояния.

## Проверка

- `templateId` уникален;
- название и описание соответствуют условию получения;
- картинка передана ссылкой или ключом;
- поля соответствуют import DTO.
